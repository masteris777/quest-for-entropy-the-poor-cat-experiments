# The Poor Cat Experiments - Quest for Entropy #14

The article **"The Poor Cat Experiments"** (Quest for Entropy #14), archived as published,
with its assets. Schrodinger's cat and Wigner's friend, read through a construct every
developer uses daily - futures/promises - and completed by the Iceberg Model's hidden
settlement layer. The two JavaScript snippets in the article run as-is in any browser
console.

The model itself - the paper, the code, and the full examination battery (including the
test rows this article cites) - lives in its own repository:
https://github.com/questforentropy/iceberg-model (DOI 10.5281/zenodo.22046196).
Reproduction instructions are there, not here.

- `article.md` - the piece as published
- `assets/` - the article's images
